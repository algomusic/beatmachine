Beat Machine Versions

The .ino.bin files for firmware updating come in a few flavors, as do the Beat Machine S3 devices.

The Wooden version is for the larger units with a lasercut wooden enclosure.
The PCB Beta was the original PCB prototype, often recognised becuase it has hand soldered wires fixing bugs.
The PCB Labelled was the version recognisable because it had inner button labels, like PLAY.

There are hardware differences between these version, meaning that the correct firmware needs to be used for correct functioning.
